2. Какие данные и зачем

  • При обращении через Telegram: имя и идентификатор аккаунта, содержание переписки — чтобы отвечать на запросы и оказывать услуги.

3. AI-обработка и трансграничная передача

Для работы AI-функций фрагменты передаваемой информации могут обрабатываться сервисами провайдеров искусственного интеллекта, серверы которых находятся за пределами РФ. Передавайте в переписку только те сведения, которые готовы доверить такой обработке. Для задач с повышенными требованиями к приватности предназначен продукт «Резидент» — обработка данных локально, без внешних сервисов.

4. Кому передаются данные

Заявка с формы отправляется на нашу электронную почту через внешний сервис доставки форм (FormSubmit). Это технический подрядчик: он получает содержимое заявки, чтобы передать её нам письмом. Сервис расположен за пределами РФ, поэтому отправляйте через форму только те сведения, которые готовы доверить такой обработке; если это неприемлемо, напишите нам напрямую в Telegram или на почту.

Данные не продаются и не передаются третьим лицам для рекламы. Доступ к ним имеют только Оператор и технические подрядчики, обеспечивающие работу Сервиса (хостинг, доставка форм, мессенджер, провайдеры ИИ) — в объёме, необходимом для работы.
